# Say Cheese downloads

Main Say Cheese Android testing builds and update information. Say Cheese Lab is excluded.

Download the latest APK from Releases on your Android phone and install it once. Later updates are offered inside Say Cheese. Android asks you to allow installs from Say Cheese and to confirm each installation.

These APKs are debug-signed private testing builds, not a Google Play production release. Existing photos and open stacks are preserved when updating an installation signed with the same key. Photos are processed locally and are not uploaded by the updater.

The developer can mark each update as optional or compulsory. Compulsory updates block continued use of the app until installed; they do not bypass Android's installation confirmation.

The source code and signing key are not stored in this repository.
